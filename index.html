📖 BORIS OS — NAVODILA ZA UPORABO

BORIS OS je tvoj osebni command center. Spodaj je razloženo, kaj vsak zavihek počne, od kod dobiva podatke in kaj moraš ročno vnašati.

● AUTO podatki se nalagajo samodejno   ● ROČNO zahteva tvoj vnos   ● ČAKA v razvoju

01 // VREME ● AUTO
Cilj
Hiter pregled vremena za vse lokacije ki so ti relevantne — Trbovlje, Žiri, Ljubljana, Novigrad, G. Radgona, Dunaj, Rogla in trenutna lokacija.
Vir podatkov
Open-Meteo API (brezplačen, brez registracije, brez CORS omejitev).
Kako deluje
Lazy init — podatki se naložijo ob kliku na zavihek. Prikazuje danes / jutri / pojutrišnjem + 7-dnevna napoved. Vremenski zajček (SVG) se obleče glede na vreme.
Ročno
Nič — vse samodejno.
02 // FINANCE ● AUTO ● ROČNO (stavnica)
Cilj
Pregled portfelja, stavnice in finančnih gibanj na enem mestu.
Portfelj
Živé cene delnic (Alphabet, Tesla, Netflix, Apple, Amazon, Microsoft, MSCI World) in kripto prek Finnhub API → Google Apps Script proxy. Prikazuje vrednost, P&L in % spremembo.
Stavnica
Ročni vnosi zneska (+ opcijsko datum za retroaktivni vnos). Shranjeno v Firebase. Kartica SPREMEMBA prikazuje diff prvega→zadnjega vnosa v izbranem obdobju (7D / 14D / 30D / VSE) z %.
Banka
Samodejno iz Firebase (placila-ebbba) — isto bazo uporablja tvoja finance aplikacija. Stanje računa, kreditna kartica, mesečni povzetek, top kategorije, graf gibanja in zadnje transakcije.
Trgovina
Samodejno iz Firebase — top kategorije nakupov iz finance aplikacije.
03 // CILJI ● ROČNO
Cilj
Vizualni tracker letnih ciljev — napredek na en pogled.
Vir podatkov
Statično — cilji in napredek so vneseni neposredno v kodo dashboarda.
Ročno
Za spremembo cilja ali vrednosti napredka je potrebna editacija HTML kode (enkrat na spremembo cilja).
04 // TODOIST NALOGE ● AUTO
Cilj
Prikaz nalog iz Todoist — kar je danes in kar je zamudilo.
Vir podatkov
Todoist MCP konektor — živi podatki direktno iz tvojega Todoist računa.
Ročno
Naloge upravljaš v Todoist (app ali splet) — dashboard jih samo prikazuje. Nič vnosa v dashboardu.
05 // GOOGLE KOLEDAR ● AUTO ● ROČNO (enkratna prijava)
Cilj
Pregled vseh Google Koledarjev v treh pogledih: dan, teden, mesec.
Vir podatkov
Google Calendar API prek OAuth 2.0. 8 koledarjev: Boris Strakl, Družinski, Rojstni dnevi, Treningi, Prazniki, Todoist, M Sora, Spielplan.
Prijava
Enkratna prijava z gumbom "PRIJAVA GCAL" v headerju. Token se shrani v localStorage — naslednjič se prijavi samodejno.
Trening
Dogodki iz "Treningi" koledarja se prikažejo v zavihku 08 kot "NAČRTOVANI TRENING". Opis treninga: TIP / KM / TEMPO / NAVODILA / KOMENTAR.
Filtriranje
Vsak koledar se vklopi/izklopi s klikom na barvni gumb filtrov.
06 // NAVADE ● ČAKA Firebase
Cilj
Dnevno sledenje navad, organiziranih po časovnih blokih (Jutro / Dopoldan / Popoldan / Večer / Noč).
Vir podatkov
Firebase (habitflow projekt) — konfiguracija v teku.
Ročno
Vsak dan obkljukaš opravljene navade v ustreznem časovnem bloku. Dnevni reset ob polnoči.
07 // FIZIČNO STANJE ● ROČNO ● AI kalorije
Cilj
Celostni pregled fizičnega stanja na telesu — prehrana, spanec, utrip, teža, koraki prikazani na holografski figuri.
Obroki
Vneseš opisni obrok v naravnem jeziku (npr. "2 jajci, toast, kava z mlekom") → Anthropic AI izračuna kalorije. Tipi: Zajtrk / Kosilo / Večerja / Prigrizek / Pijača.
Voda
Klik na + za vsak kozarec (2,5 dl). Dnevni cilj nastavljiv (privzeto 25 dl).
Spanec
Ročni vnos ure vstajanja in ure spanja — točka prikazana na figuri (vijolična).
Utrip
Ročni vnos srčnega utripa (BPM) — točka na figuri (rdeča).
Teža
Ročni vnos teže zjutraj — točka na figuri (modra). Cilj: 82 kg.
Koraki
Ročni vnos korakov — točka na figuri (zelena).
Shranjevanje
Vse shranjeno v localStorage. Dnevni reset ob polnoči — obroki in voda se pobrišejo, cilji ostanejo.
08 // ŠPORT · GIBANJE ● ROČNO (vaje) ● Strava čaka MCP
Cilj
Pregled tekaških aktivnosti, načrtovanega treninga in dnevnih telesnih vaj na enem mestu.
Načrt. trening
Samodejno iz Google Koledarja (Treningi) — prikaže današnji trening z vsemi podrobnostmi (tip, km, tempo, navodila, komentar).
Zadnji tek
Trenutno hard-coded placeholder. Čaka Strava MCP — konektor je povezan, Strava pa postopoma odpira dostop (eligible: false). Ko bo aktiven, bo prikazoval žive podatke.
Mesečni km
Placeholder — prišlo bo iz Strava MCP.
Telesne vaje
Ročni vnos serij: izbereš vajo (🧘 Plank / 🏋️ Počepi / 💪 Sklece), vneseš vrednost, klikneš +. Serije se seštevajo čez dan. Dnevni reset ob polnoči. Shranjeno v localStorage.
10 // ŠPORTNE PRIREDITVE ● ROČNO (v kodi)
Cilj
Countdown in sledenje pripravi na tekaške prireditve — koliko tednov do starта, tedenski trening plan.
Vir podatkov
Statično — prireditve so vnesene neposredno v kodo dashboarda.
Trenutno
Maraton treh src (Radenci), 13. september 2026 — polmaraton, ciljni čas 2:00:00.
Ročno
Za dodajanje ali spremembo prireditve je potrebna editacija HTML kode.
11 // KNJIŽNICA ● ROČNO ● Firebase sync
Cilj
Sledenje knjigam — kaj bereš, čakalna vrsta, prebrano in analitika po jeziku/viru/žanru.
Vir podatkov
Firebase (placila-ebbba / books.json) — sinhronizirano med vsemi napravami.
Dodajanje
Klik "+ DODAJ KNJIGO" → vneseš avtorja, naslov, jezik (SLO / DE / EN), vir (Knjižnica Trbovlje / Kindle / Še ni jasno), napredek.
Naslovnice
Prilepiš sliko iz odložišča (Ctrl+V) ali naloži datoteko. Shrani se kot base64 v Firebase.
Napredek
Fizična knjiga → strani (prikazano v %). Kindle → % direktno.
Zavihki
BEREM · ČAKALNA VRSTA (razvrščeno po jezikih) · PREBRANO · ANALITIKA (grafi po jeziku, viru, žanru).
12 // TV SERIJE ● ROČNO ● Firebase sync
Cilj
Sledenje TV serij — kaj gledaš, seznam po platformah, gledano in analitika.
Vir podatkov
Firebase (placila-ebbba / shows.json) — sinhronizirano med napravami.
Dodajanje
Klik "+ DODAJ SERIJO" → platforma, žanr, sezona/epizoda, skupaj sezon/epizod. Plakat: prilepi (Ctrl+V) ali naloži.
Napredek
Progress bar S01E05 z %. Hitri gumb "✔ ZAKLJUČI SEZONO" skoči na naslednjo S+1 E01. "🏁 ZAKLJUČI SERIJO" premakne v GLEDANO.
Zavihki
GLEDAM · SEZNAM (po platformah: Netflix, HBO Max, Prime, Apple TV+, Disney+, Voyo, EON…) · GLEDANO · ANALITIKA.
13 // FILMI ● ROČNO ● Firebase sync
Cilj
Sledenje filmov — kaj gledaš, seznam po virih, gledano in analitika.
Vir podatkov
Firebase (placila-ebbba / films.json) — sinhronizirano med napravami.
Dodajanje
Klik "+ DODAJ FILM" → vir (vse platforme + 🎬 Kino + 📺 TV), žanr, status. Plakat: prilepi (Ctrl+V) ali naloži.
Razlika od serij
Ni sledenja sezon/epizod. Ob dodajanju je možen direkten status "Že gledano".
Zavihki
GLEDAM · SEZNAM (po virih) · GLEDANO · ANALITIKA (po platformah, žanrih, ocenah).
14 // EV — ŠKODA ENYAQ ● Google Sheets
Cilj
Statistike porabe energije, polnjenj in dosega za Škoda Enyaq iV 60.
Vir podatkov
Dve Google Sheets preglednici prek Google Apps Script: km sledenje + polnjenja. Obe morata biti nastavljeni na "Kdorkoli s povezavo → Ogledovalec".
Ročno
Vnose delaš v Google Sheets (km stanje, datum/kWh/lokacija polnjenja) — dashboard podatke samo prikazuje.
Zavihki
PREGLED (skupaj km, kWh/100km, ocenjeni doseg, baterija bar) · POLNJENJA (seznam po mesecih, brezplačne/plačane seje z barvnimi tagami) · STATISTIKA.
Baterija
55,1 kWh dejanska kapaciteta (58 kWh neto, 95% SOH). Brezplačni % se računa po kWh (ne po sejah).
